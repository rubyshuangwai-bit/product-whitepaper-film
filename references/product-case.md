# 虚构产品的完整演示

包内 `examples/whitepaper-demo` 包含一份专用于测试的虚构白皮书、口播和可编辑动画。没有真实客户资料、个人信息或产品截图。

演示主线：说明产品定位 → 展开资料导入、关键词查找、原文查看 → 界面重点和来源关系随讲述变化 → 清楚标示流程示意。

素材为自行绘制的示意界面；宣传文案只使用虚构白皮书中的设定，不加入速度、模型能力或兼容范围。白皮书和口播不是对真实产品能力的证明。

示例时间轴由人工编排，仅演示动画结构，不对应任何个人配音、产品实测或验收记录。添加自己的合法配音后，重新对齐并检查实际输出。

不要把此案例的步骤、字段、布局或时间照搬到所有产品。更换产品或配音时，重新读资料并对齐口播与画面。
